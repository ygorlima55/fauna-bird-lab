# Fauna Bird Lab (versão de teste)

App experimental para **identificar aves pelo som, no próprio celular e sem internet**, usado para testar um
pipeline que depois será levado para a identificação de anfíbios anuros.

**Abrir:** https://ygorlima55.github.io/fauna-bird-lab/  (Chrome no Android; no 1º acesso baixa ~95 MB, use Wi-Fi)

- Grave e veja o espectrograma ao vivo e as espécies prováveis (modelo BirdNET+, roda no aparelho).
- Importe áudios (MP3, WAV, M4A, FLAC) e veja o relatório.
- Histórico com áudio, sonograma, GPS e ficha de campo; aba Espécies com fotos e sons de fontes abertas.
- **Quer ajudar?** Abra uma sessão no Histórico e toque em *Enviar para a pesquisa*. Nada sai do celular sem você mandar.

Escore do modelo não é probabilidade: confirme sempre pela observação.
